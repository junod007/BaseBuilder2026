# Day 03 - Building an ERC721 NFT

Today I built a simple ERC721 NFT smart contract as part of my Base Builder journey.

## Contract

**Contract Name:** MyNFT  
**Token Standard:** ERC721  
**Network:** Base Sepolia Testnet  

## Features

- ERC721 NFT standard
- NFT name and symbol
- Mint function
- Token ownership tracking
- Token ID management

## What I Learned

Today I learned how ERC721 tokens are different from ERC20 tokens.

Unlike ERC20 tokens, where every token unit is interchangeable, each ERC721 token can have its own unique Token ID.

I also learned about:

- NFT ownership
- Token IDs
- Minting NFTs
- Smart contract deployment
- Testing contract functions on Base Sepolia

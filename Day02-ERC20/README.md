# Day 02 - Building an ERC20 Token

Today I built and deployed my first simple ERC20-style token smart contract on Base Sepolia.

## Contract

**Token Name:** Base Builder Token  
**Symbol:** BBT  
**Decimals:** 18  
**Initial Supply:** 1,000,000 BBT

## Features

- Token name
- Token symbol
- 18 decimals
- Initial token supply
- Balance tracking
- Token transfer function

## Smart Contract Functions

### balanceOf

Checks the token balance of an address.

### transfer

Transfers tokens from the sender to another wallet address.

The transfer function was tested successfully on Base Sepolia.

## Testing

The contract was compiled and deployed successfully using Remix IDE.

Tests completed:

- Contract deployment
- Initial supply verification
- Token balance check
- Token transfer
